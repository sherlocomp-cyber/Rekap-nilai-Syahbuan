🔄 Sinkronisasi ke Firebase

⚠️ Isi URL Realtime Database milik Anda SENDIRI di bawah (lihat panduan "Cara membuat Firebase Realtime Database"). Jangan pernah membagikan file HTML ini ke orang/sekolah lain setelah URL diisi — kalau Rules database masih dalam mode terbuka, siapa pun yang tahu URL ini bisa membaca maupun MENIMPA data ini. Kalau ingin membagikan aplikasi kosong (tanpa data & tanpa URL) ke sekolah lain, gunakan "Reset semua data" dulu lalu kosongkan kolom URL sebelum membagikan filenya. App memeriksa data terbaru dari Firebase setiap ±45 detik selama dibuka (kalau "Sinkron otomatis" aktif). Sekarang aman dipakai beberapa perangkat bersamaan: setiap kali menyimpan, app menarik data server dulu lalu MENGGABUNGKAN dengan data di perangkat ini (bukan menimpa total), jadi input dari guru lain tidak hilang. Jangan edit data di Firebase Console secara manual kecuali Anda yakin strukturnya — isinya data mentah, bukan tabel nilai.
Setelah URL (dan Secret bila dipakai) terisi, tekan salah satu tombol di atas sesuai kebutuhan (lihat panduan di bawah).
Belum terhubung ke Firebase.
Cara membuat Firebase Realtime Database (sekali saja)
  1. Buka console.firebase.google.com, login dengan akun Google, lalu klik Add project / Tambahkan project dan ikuti langkahnya (Google Analytics boleh dimatikan).
  2. Di menu sebelah kiri, buka Build → Realtime Database, lalu klik Create Database. Pilih lokasi server terdekat (mis. Singapore).
  3. Saat diminta mode keamanan, pilih Start in test mode dulu supaya cepat jalan (baca/tulis masih terbuka — nanti diperketat di langkah berikutnya).
  4. Setelah database dibuat, salin URL yang tertulis di bagian atas halaman (bentuknya https://xxxxx-default-rtdb.asia-southeast1.firebasedatabase.app), tempel di kolom "URL Firebase Realtime Database" di atas.
  5. (Disarankan) Buka tab Rules pada Realtime Database, ganti isinya dengan aturan yang mewajibkan secret, lalu klik Publish. Lihat contoh Rules dan cara membuat Secret di jawaban chat.
  6. Klik "Simpan ke Firebase sekarang" satu kali di aplikasi ini untuk mengirim data pertama.

Cadangan Data

Ekspor seluruh data aplikasi sebagai file cadangan, atau impor kembali di perangkat lain. Sebelum "Tarik dari Firebase", "Impor", atau "Reset", aplikasi otomatis menyimpan snapshot darurat & mengunduh cadangan.

Nilai Ujian (UTS / STS)

Nilai bagian A/B/C digabung, dikatrol, lalu nilai TP raport dihasilkan otomatis (acak proporsional) untuk keperluan raport sementara. Batas bawah & batas atas katrol tetap custom (isi manual), tapi acuan nilai TERENDAH dan TERTINGGI yang dipetakan ke batas bawah/atas itu diambil dari gabungan seluruh kelas paralel (mis. kelas A & B dalam satu kelompok/tingkat) — bukan dari kelas ini sendiri — supaya kedua kelas memakai skala katrol yang sama & adil.
Tips: setelah mengisi nilai A/B/C, gunakan tombol arah keyboard (◀️▶️ pindah antar A/B/C, 🔼🔽 pindah antar siswa) untuk mengisi lebih cepat tanpa menyentuh mouse.

🔑 Kunci Jawaban (Kunci Soal)

Pilih mata pelajaran & tingkat kelas, tentukan jumlah soal, lalu tandai kunci jawaban tiap nomor. Kunci jawaban berlaku untuk semua kelas paralel dalam satu tingkat (mis. kelas 3A & 3B pakai kunci yang sama, terpisah dari kelas 4A & 4B). Pilih "Bonus" untuk soal yang tidak punya jawaban benar (semua siswa otomatis dianggap benar).

👥 Pengaturan Kelompok Siswa

📥 Isi Template Excel (SAS & Sumatif)

Unggah template Excel (satu atau banyak mapel sekaligus). Kelas & mapel dikenali otomatis dari sel "Kelas/Mapel" di template. Kolom Nilai diisi dari nama siswa: sheet SAS dari nilai ujian, sheet SUM dari nilai TP. Di sheet SUM, Materi dan KKTP juga bisa diisi. Bagian lain file tidak diubah sama sekali.
⚙️ Sumber nilai TP per sheet SUM
Pilih sumber nilai TP untuk masing-masing sheet SUM. "Ikuti bawaan" memakai pilihan di atas.
📚 Daftar Materi per TP
Materi TP ke-n diisikan ke kotak Materi pada sheet SUM yang memakai TP ke-n. Daftar ini berlaku untuk semua kelas paralel pada tingkat yang sama (mis. materi 4A Bahasa Arab otomatis sama untuk 4B) dan tersimpan otomatis.
Nilai ujian mengikuti pilihan ujian & jenis nilai (katrol/akhir) di "Atur Penilaian Rapor". Jumlah TP yang tersedia juga mengikuti pengaturan itu. Sel yang nilainya belum ada dibiarkan kosong.
